# Releasing CVS Desk

CVS Desk is published from Git tags. Every push and pull request runs CI;
only a `v*` tag produces downloadable files.

## Versioning

- Versions follow `MAJOR.MINOR.PATCH`, and the tag is `vX.Y.Z`.
- Before 1.0, a feature or breaking change bumps the minor version; a fix bumps the patch.
- The tag must match `version` in `Cargo.toml`. The release workflow checks this.
- A release candidate is tagged `vX.Y.Z-rc.N`. It is marked as a prerelease and does not
  become the "latest" release.

## Before tagging

1. Run `cargo fmt --all -- --check`.
2. Run `cargo test --locked`.
3. Run `cargo build --release --locked`.
4. Run `target\release\cvsdesk.exe` and check that the About dialog shows the version.
5. Run `target\release\cvs.exe --version` and check the version at the end of the banner.
6. Update `CHANGELOG.md`, and update `version` in `Cargo.toml` if needed.
7. Commit and push `main`, then wait for CI to pass.

## Dry run

Run the Release workflow manually from the Actions page (or with
`gh workflow run release.yml`). It builds the zip and keeps it as a workflow artifact for
seven days; it does not create a release.

Download the artifact, extract it on a clean Windows machine, and run both programs.
Windows Sandbox is enough for this check.

## Publishing

```text
git tag -a v0.1.0 -m "CVS Desk 0.1.0"
git push origin v0.1.0
```

The workflow:

1. checks the tag against `Cargo.toml`;
2. runs formatting, tests, and the release build;
3. packs `cvsdesk.exe`, `cvs.exe`, `README.md`, `LICENSE`, `third-party-licenses.txt`
   (generated by `cargo about`), and `CHANGELOG.md` into
   `cvsdesk-vX.Y.Z-windows-x64.zip`;
4. writes `SHA256SUMS.txt`;
5. creates the GitHub Release with generated notes.

Verify the release page, download the zip, and compare its SHA-256 with
`SHA256SUMS.txt`.

## If a release is wrong

Do not move or replace a published tag. Fix the problem, bump the patch version, and
publish a new release. If the release is a draft, or was published moments ago and has no
useful downloads, delete the release and the tag, fix the problem, and tag again.

## Signing and installers

The current release is an unsigned portable zip. Windows SmartScreen may warn about it.
Signing and a per-user installer are planned; until then, the README explains how to verify
the download.
